# Technique scorecard: what `quad` measures every 4 bars (and what stays manual)
Source: original_technique_map.md sections 3-5, genius_line_classes.md, bars_1-8_breakdown.md. No lyrics stored.

## Measured by `python toolkit/rhyme_tools.py quad FILE` (per 4 bars)
| Field | Technique (map ref) | Original, Ch L1-4 |
|---|---|---|
| syl | line-length shape, stair-steps (s2) | 5, 9, 9, 9 |
| scheme2 / end_cover2 | end rhyme on the last 2 syllables; monorhyme coverage (s5.2) | AAAA (EY-OW), 4/4 |
| scheme1 | last-vowel scheme (misses 2-syl rhymes) | - |
| fem_end | weak/feminine endings (s5.2) | most |
| enjamb | bar ends on a pronoun/function word (s5.6) | 0 |
| internal_bars | mid-bar rhyme with the end vowel (s4) | sparse |
| multisyl / mosaic | multisyllabic and cut-up rhymes (s4, s5.5) | luego~Tobago~plain clothes~plane home |
| perfect_pairs / homophones | perfect rhymes; same-onset homophone pun (plain/plane) | homophone 1 |
| allit_bars | alliteration (s4) | L2 (B), L3-4 (PL/KL across bars) |
| carpet | vowel carpet density (s4) | EY dominant |
| echo_words | echo with a twist (s5.7) | - |
| numbers | number ladder (s5.8) | 0 |
| redup | onomatopoeia/reduplication (s4) | 0 |
| mate | voice tic (s5.14) | 0 |

## Manual (judged in /review)
Roll-call greetings (accurate), pun pair, stock phrase cashed in the rhyme slot, bathos by British mundanity, understated menace, lexical set as extended metaphor, echo with a twist, number ladder, AXAA break, hinge line, enjambment, voice tics, escalation then montage.
