## Rhyme map
- **Hook:** AA BB CC DD couplets on place names, with multis (Pyrenees / three, seven / Devon, eight / wait). Replies: No way (Norway pun), Two years, Worldwide.
- **Verse 1:** three 4-bar monorhyme blocks that switch at story beats: -air (declare / stare / Fair / underwear), -ee (tea / knee / oui / free), -on (jamón x3 / dawn / prawn / gone). Punchlines land on the last stressed word of each block (underwear, free, gone).
- **Verse 2:** -ain (Dane / pain / complain / vain / rain / again), then -el (cartel / well / hell / falafel, the feminine closer).
- **Verse 3:** one 8-bar -ight block (night / fight / fright / sight / Right / kite / Alright / goodnight), with callbacks to the chalk and Great Dane bits.
- Deflation structure: global boast, then a tiny British comedown (twelve-quid pint, chickpeas from a tin, in bed by seven, quarter to nine, goodnight).
